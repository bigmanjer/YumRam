# YUMRAM v5.2.53 — Research Quality Fix

## Research contract
- Web research requires a durable identity anchor (executable/file, signer/hash, publisher/product, strong local catalog, or strong service evidence).
- Known Windows system identities such as Memory Compression never use generic web research.
- Search-engine result pages are discovery only and are never persisted as verified evidence.
- Verified sources require both authoritative trust and identity-bearing content.
- ResearchLinks contains only verified source URLs; raw discovery URLs are not treated as evidence.
- Unknown is a terminal research outcome when safe identity corroboration is impossible.
- ResearchRunResolved is true for every eligible item that reaches Organized or Unknown.
- Launcher and startup architecture are unchanged from the confirmed stable baseline.
