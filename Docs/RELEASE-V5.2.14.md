# YUMRAM V5.2.14

## Research/persistence hardening
- Explicit terminal state model: Organized, Unknown, Review, Research Error.
- Cached Organized results are terminal only when placement is genuinely resolved; conservative Startup Inventory remains organized.
- ResearchExhausted is true only for terminal Organized/Unknown results.
- Research count excludes terminal results and tracks unresolved work.
- Stable intelligence identities no longer depend on volatile process PIDs.
- Manual organization identity can use executable hash/signer and migrates legacy overrides.
- Research queue JSON crossing the worker boundary is explicitly typed as one string.
- Saved Intelligence records are normalized through the canonical schema before display.
- Release metadata is consistently V5.2.14.
