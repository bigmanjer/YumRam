## YUMRAM 5.17.2 - Yume's Ultimate Machine Rescue And Maintenance

YUMRAM now stands for **Y**ume's **U**ltimate **M**achine **R**escue **A**nd **M**aintenance - named for Yume 💜.
You can see it on the About page. The program keeps its name, so your settings and automatic updates are unchanged.

Also: the About page lists the shortcuts for Disk cleanup (Ctrl+9) and Uninstall programs (Ctrl+0).

Recent: 5.17.1 added a progress bar to Disk cleanup (it says when the clean is finished and updates the list by
itself); 5.17.0 added Uninstall programs with leftover clean-up.

### How to check the download
Compare the SHA-256 of `YUMRAM-Setup-5.17.2.exe` with `SHA256SUMS.txt`. The installer is not code-signed yet, so
SmartScreen may say "Windows protected your PC" - choose More info > Run anyway.
