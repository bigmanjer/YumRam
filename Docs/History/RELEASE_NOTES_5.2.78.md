# YUMRAM 5.2.82

## Automatic research during Run Scan

RUN SCAN is now the single normal Intelligence workflow. The scan builds the live inventory, merges saved intelligence, and automatically launches research for live records that remain unresolved.

The standalone RUN RESEARCH control is hidden from the normal UI. Selected-item research remains available for an explicit fresh investigation.

Known/cached identities are reused. Only unresolved identities enter the research queue.
